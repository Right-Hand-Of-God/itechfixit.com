# Infinity-Tech-Fhjk

## Project layout

- `frontend/` contains the storefront, admin interface, browser scripts, styles, and images. Publish this folder for GitHub Pages.
- `backend/` contains the local Python server, SQLite catalog, migration utility, and Supabase schema.
- `start-local.bat` starts the local development server. See [LOCAL-CATALOG-SETUP.md](./LOCAL-CATALOG-SETUP.md) for setup.
